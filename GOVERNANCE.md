# Quản trị DX-TRACE

Người đóng góp đề xuất thay đổi qua issue hoặc pull request. Maintainer đánh giá tương thích dữ liệu, giấy phép và kết quả CI trước khi hợp nhất. Các bản phát hành được nhận diện bằng Git tag và checksum của source archive. Xem [hướng dẫn đóng góp](CONTRIBUTING.md), [tác giả](AUTHORS.md), [chính sách bảo mật](SECURITY.md) và [quy trình vận hành](docs/DXOS-GOVERNANCE.md).

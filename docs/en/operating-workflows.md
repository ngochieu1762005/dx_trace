# Operating workflows

## Integrated operations

The task inbox highlights authorized work and overdue items. A rejected quality inspection can be linked to a quarantine incident. Parallel workflow tasks and timers have persisted state. Audit evidence can be exported and checked independently.

## Acceptance

Use a training lot, two authorized identities and actual before/after counts. Confirm Core blocks prohibited transitions and shipment, then inspect ledger and evidence.

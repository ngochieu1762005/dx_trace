# Roadmap

## Priorities

Continue strengthening deployment acceptance, model evolution, workflow coverage, data governance, backup/recovery and integration evidence. PostgreSQL runtime, dynamic role provisioning and complete SSO/performance evidence are separate future work, not delivered features.

Review the canonical roadmap and releases for dated commitments.

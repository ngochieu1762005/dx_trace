# Security

## Report responsibly

Do not publish exploit details or sensitive records in public issues. Use the project's documented security contact and provide the affected version, environment, impact and minimal reproducible information from authorized testing. Avoid accessing unrelated accounts or real data.

Core and service credentials are private. Report suspected secret exposure and rotate affected credentials.

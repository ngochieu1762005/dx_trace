# BPMN interchange

## Supported subset

The workflow import/export layer maps a documented BPMN subset to the finite-state definition. Preview imports before applying, verify model ID and version, and avoid unsupported elements. Export orchestration separately when present.

This is not a complete BPMN 2.0 execution engine or arbitrary XML script runner. See [process runtime](process-runtime.md).

# Declarative models

## Model lifecycle

Validate a definition, preview impact, apply with baseVersion, and retain version history. The Core rejects destructive changes that invalidate records or alter active workflows. Definitions generate form metadata and per-model OpenAPI.

## Records

Create according to allowed roles; updates require the creator and initial state. State transitions enforce permissions, guards, reasons and optimistic versions. Read queries apply record scope before pagination and counts.

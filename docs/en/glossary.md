# Glossary

| Term | Definition |
| --- | --- |
| Workspace | Isolated data and authorization scope |
| Headless Core | Business service independent of presentation |
| Manifest | Declarative model, permissions and workflow definition |
| Bundle | Atomic installation of multiple manifests |
| Idempotency key | Stable identifier for retrying the same command |
| Optimistic locking | Rejects writes against an outdated version |
| RBAC | Role-based access control |
| SSO | Single sign-on through the identity provider |
| BPMN | Business Process Model and Notation; supported subset only |
| Quarantine | Blocks shipment or file download until conditions are met |
| SBOM | Software bill of materials |
| Audit checkpoint | Externally retained ledger head for comparison |

## Which identifier answers which question?

A **product barcode** identifies an item on its packaging. A **lot code** identifies a stock batch with its own expiry and storage conditions. A **shipment ID** identifies a delivery to one destination. For a partial return, start with the shipment to attribute the returned quantity, then reconcile the remaining balance for the lot.

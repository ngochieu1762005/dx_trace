# Contributing

## Workflow

Create a focused branch, use reproducible tests and clear commit messages, avoid credentials or personal data, and submit a reviewable pull request. Changes to data contracts need migration/compatibility tests. Update the relevant docs and English counterpart.

```bash
pnpm install --frozen-lockfile
pnpm test
```

Respect the project's license, code of conduct and security reporting process.

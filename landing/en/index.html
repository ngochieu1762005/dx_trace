BEFORE YOU START

Frequently asked questions.

Which account should I use?

Use the account issued by your administrator in the warehouse realm. After sign-in, you enter your workspace.

What do the figures on this page represent?

The landing page figures illustrate the workflow. Application data is stored according to workspace and account permissions.

Can I install it on my own computer?

Yes. The source includes a Node.js 24 demo. Multi-account deployment uses Docker Compose and Keycloak. See the README for installation options.

How is the software licensed?

Project source uses MIT. Libraries, fonts and Open Food Facts data have separate licenses documented in the repository.
